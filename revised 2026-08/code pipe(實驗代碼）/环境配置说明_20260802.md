# 本機（M1 16GB）Python 環境配置説明（2026-08-02）

## 一、"總是報錯"的原因（已查明）

本機同時裝有兩套 Python：

| 解釋器 | 版本 | 來源 | 科學計算依賴 |
|---|---|---|---|
| `/usr/local/bin/python3.13` | **3.13.7** | python.org 官方安裝包 | **全套齊備**（numpy/scipy/sklearn/matplotlib/pandas/openpyxl/torch 2.10.0/transformers 4.57.6/tkinter） |
| `/opt/homebrew/bin/python3` | 3.14.5 | Homebrew | **缺** scipy、sklearn、pandas、torch、transformers、tkinter |

問題：Homebrew 升級後，終端 PATH 裏 `python3` 默認指向 **3.14.5**。直接敲
`python3 "small pipe 5.2.py"` 會落到 3.14 上，立刻 `ModuleNotFoundError`
（缺 scipy/pandas/tkinter 等）。**Python 3.14 本身裝好了，但它的包環境是空的；
以前所有成功運行（含 202608012355 供刊運行）用的都是 3.13。**

## 二、正確用法（記住一條就夠）

**跑本項目一律顯式用 `python3.13`，不要用裸 `python3`：**

```bash
python3.13 run_small_pipe52_headless.py        # 無頭重跑（供刊複現）
python3.13 "small pipe 5.2.py"                 # GUI 版
python3.13 "pipeline21.1.py"                   # GUI 版（語義/重排需模型文件）
```

或直接雙擊本目錄下的 `啓動small pipe 5.2.command` / `啓動pipeline21.1.command`。

## 三、兩個腳本的運行前提

- **small pipe 5.2**：純 TF 通道（TF-cos/TF-IDF/Jaccard/PCA/Ward/Strength），
  3.13 環境開箱即跑；無頭複現約 35 秒。
- **pipeline21.1**：字面通道同上可跑；語義通道（Qwen3-Embedding/BGE-M3）與
  Reranker 需本地模型文件（HuggingFace snapshot 目錄），其中 8B 模型 M1 16GB
  **跑不動**（需外部 GPU），0.6B/BGE 可在 MPS 上運行。刊面已刪 Reranker 列，
  重排通道僅供倉庫復現，不影響論文任何數值。

## 四、鎖定版本（供異機複現）

`requirements_py313_freeze.txt` 爲本機 3.13 環境實測凍結版本（僅列本項目用到者）。
異機複現：

```bash
python3.13 -m venv venv && source venv/bin/activate
pip install -r requirements_py313_freeze.txt
```

## 五、若一定要修 Homebrew 3.14（可選，不推薦）

```bash
python3.14 -m pip install numpy scipy scikit-learn matplotlib pandas openpyxl networkx python-docx pymupdf
```

torch/transformers 在 3.14 的輪子與 tkinter（需 `brew install python-tk@3.14`）
另裝；但 3.13 已驗證可用且與供刊運行同環境，**建議保持 3.13，不動 3.14**。
